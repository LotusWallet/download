安装步骤

  1. 下载上面的 APK 文件。
  2. 系统提示「不允许安装未知来源应用」时，前往设置里为本浏览器 / 文件管理器放行。
  3. 打开安装包完成安装，首次启动会让你设置主密码。
  4. 没有注册，也没有账号。主密码和助记词请自行离线备份 —— 丢了我们无法帮你找回。

校验下载完整性

把结果与本页显示的 sha256 对比。两者一致，说明文件在传输过程中没有被改动。

Linux / macOS：
shasum -a 256 LotusWallet-*.apk

Windows PowerShell：
Get-FileHash .\LotusWallet-*.apk -Algorithm SHA256
